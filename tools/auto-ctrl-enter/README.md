# أداة تكرار Ctrl+Enter تلقائياً

أداة صغيرة مستقلّة تُرسل ضغطة **Ctrl+Enter** كل **3 ثوانٍ** (قابلة للتغيير)
إلى النافذة النشطة على جهازك.

> ملاحظة: هذه أداة سطح مكتب وليست جزءاً من تطبيق الويب في هذا المستودع؛
> تُشغَّل على جهازك مباشرةً لأنها تتحكّم بلوحة المفاتيح.

---

## الخيار ١ — ويندوز بدون تثبيت بايثون (الأسهل)

1. حمّل **AutoHotkey v2** من [autohotkey.com](https://www.autohotkey.com/) وثبّته.
2. انقر نقراً مزدوجاً على `auto-ctrl-enter.ahk`.
3. انتقل إلى النافذة التي تريدها واضغط **F8** للبدء.

| المفتاح | الوظيفة |
|---|---|
| `F8` | تشغيل / إيقاف مؤقّت |
| `F9` | إنهاء الأداة |

لتغيير الفاصل الزمني: افتح الملف بمحرّر نصوص وعدّل السطر
`global IntervalMs := 3000` (بالمللي ثانية، 3000 = 3 ثوانٍ).

---

## الخيار ٢ — بايثون (ويندوز / ماك / لينكس)

```bash
pip install -r requirements.txt
python auto_ctrl_enter.py
```

على ويندوز يمكنك ببساطة تشغيل `run.cmd` (يثبّت المتطلّبات ويشغّل الأداة).

### الخيارات

| الخيار | المعنى | الافتراضي |
|---|---|---|
| `-i, --interval` | الفاصل الزمني بالثواني | `3` |
| `-k, --keys` | الاختصار المُرسَل | `ctrl+enter` |
| `-n, --count` | التوقّف بعد هذا العدد من الضغطات (`0` = بلا حدّ) | `0` |
| `-d, --delay` | عدّ تنازلي قبل البدء بالثواني | `3` |
| `--wait` | لا تبدأ تلقائياً، انتظر ضغط `F8` | — |

### أمثلة

```bash
python auto_ctrl_enter.py                 # Ctrl+Enter كل 3 ثوانٍ
python auto_ctrl_enter.py -i 1.5          # كل ثانية ونصف
python auto_ctrl_enter.py -n 20           # 20 ضغطة ثم يتوقف تلقائياً
python auto_ctrl_enter.py -k alt+s        # اختصار مختلف
python auto_ctrl_enter.py --wait          # لا يبدأ إلا بعد ضغط F8
```

### التحكّم أثناء التشغيل

| المفتاح | الوظيفة |
|---|---|
| `F8` | تشغيل / إيقاف مؤقّت |
| `F9` | إنهاء |
| `Ctrl+C` | إنهاء من نافذة الطرفية |

الاختصارات المدعومة في `--keys`: المُعدِّلات `ctrl` و`alt` و`shift` و`win`،
مع مفتاح أساسي مثل `enter` أو `tab` أو `space` أو `f1`–`f12` أو أي حرف مفرد.

## ملاحظات مهمّة

- **الضغط يذهب إلى النافذة النشطة** أياً كانت. تأكّد من وضع المؤشّر في المكان
  الصحيح قبل البدء — لهذا يوجد عدّ تنازلي 3 ثوانٍ افتراضياً.
- **ماك**: يتطلّب منح إذن *Accessibility* لتطبيق الطرفية من
  System Settings → Privacy & Security → Accessibility.
- **لينكس**: يعمل على X11. على Wayland قد لا يُسمح بمحاكاة لوحة المفاتيح؛
  استخدم جلسة X11 أو أداة مثل `ydotool`.
- **مفتاح الإيقاف دائماً متاح**: `F9` يُنهي الأداة فوراً، وإغلاق النافذة يوقفها.
- استخدم الأداة على حساباتك وأدواتك الخاصة، والتزم بشروط استخدام أي خدمة
  تُشغّلها عليها (كثير من الخدمات تمنع الإرسال الآلي المتكرر).
